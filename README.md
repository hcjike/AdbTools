# AdbTools

一款基于 WPF（C#）开发的 Windows 桌面工具，封装了 ADB（Android Debug Bridge）常用命令，提供图形化界面实现 Android 设备的**无线连接、配对、设备管理与应用调试**，无需记忆命令行。内置 `adb.exe` 及依赖，开箱即用。

## 功能特性

- **无线连接**：输入 `IP:端口` 即可无线连接设备，支持省略端口（默认 `5555`）。
- **无线配对**：配对窗口内置「扫码配对 / 配对码」切换条（默认扫码）。扫码配对由工具生成二维码（协议同 Android Studio），手机端「使用二维码配对设备」扫码后自动完成配对、连接在后台静默进行；也可切到「配对码」手动输入 `IP:端口` 与配对码配对。配对成功即时提示，无需等待连接。
- **连接管理**：设备列表展示、一键刷新（`F5`）、断开单个 / 断开所有设备。
- **历史记录**：自动保存成功连接的地址，下拉框可右键「删除记录 / 清空所有记录」。
- **应用安装**：右键设备行「安装应用」选择 APK，或直接把 APK 文件**拖拽**到设备行安装。
- **应用控制**：查看 / 启用 / 禁用应用包名（系统 / 第三方 / 全部），支持一键禁用（特殊设备）。
- **设备调试**：打开 Shell 窗口、实时日志 / Debug 日志查看、恢复默认 TCP 端口 / 分辨率 / DPI。
- **操作日志**：独立日志窗口记录操作过程与状态，可右键复制命令。
- **其它**：窗口置顶、关于信息、项目地址（含镜像）、检查更新（Gitea 仓库镜像）。

## 开发环境

- 开发工具：Visual Studio 2019 / 2022
- 框架：`.NET Framework 4.6`
- 平台：`x64`

## 运行环境

- 需要 `.NET Framework 4.6` 运行时；
- `64 位 Windows` 系统；
- 程序已内置 `adb.exe` 及依赖（`AdbWinApi.dll`、`AdbWinUsbApi.dll`、`QRCoder.dll`），**无需电脑另行安装 ADB 或 VC++ 运行库**，Windows 10/11 开箱即用。adb 命令会自动拉起自带服务，不依赖系统中已存在的 adb 服务（Win7/8/8.1 需系统已安装 Universal C Runtime 更新）。

## 连接准备

[观看视频](/docs/videos/1.mp4)

### 开启开发者模式

`设置 - 关于 - 版本号`，连续点击 `7 次` 开启开发者模式。

### 安卓 11 及以上

`设置 - 系统 - 开发者选项`，找到 `无线调试`，连接 WiFi 后开启，进入 `无线调试` 查看 `IP 地址和端口`，使用该地址即可无线连接。

> 注：部分设备入口位置不同，请自行寻找。

### 安卓 11 以下

连接 WiFi 后查看设备 `局域网 IP 地址`，使用该地址即可无线连接，此时无需输入端口号。

> 注：过低版本的设备可能无法连接。

## 安装和使用

- 解压到 **不含空格和中文** 的目录；
- 运行 `AdbTools.exe` 即可使用。

## 使用说明

### 设备配对（Android 11+）

配对窗口顶部提供「扫码配对 / 配对码」切换条，**默认进入扫码配对**。

**方式一：扫码配对（推荐，默认）**

1. 点击「配对 (`F8`)」打开配对窗口（默认即为扫码界面）；
2. 工具生成配对二维码（协议与 Android Studio 一致），上方高亮条提示手机操作路径；
3. 手机在「无线调试 - 使用二维码配对设备」界面扫描二维码，工具自动发现设备并完成配对；配对成功后**立即弹窗提示**，连接在后台自动完成（无需等待）。

> 注：部分老设备 ADB Wi-Fi 版本较低（v1.0）配对能力受限，扫码失败时请改用方式二。

**方式二：输入配对码**

1. 在配对窗口点击「配对码」切换到手动模式；
2. 在设备「无线调试 - 使用配对码配对设备」中获取 `IP:端口` 与配对码；
3. 输入**配对地址**与**配对码**，点击「配对 (`Enter`)」或按回车完成。

### 设备连接

1. 在「IP 和端口」输入框中输入设备的 `IP:端口`（可省略端口，默认 `5555`）；
2. 点击「连接 (`Enter`)」或按回车，等待连接成功。

### 历史记录

- 连接成功的地址会保存在下拉历史中；
- 展开输入框右侧下拉，右键某条记录可进行「删除记录 / 清空所有记录」。

### 设备列表操作

右键已连接设备，可进行的操作：

| 菜单 | 说明 |
| --- | --- |
| 安装应用 | 选择 APK 文件安装到该设备 |
| 断开设备 | 断开当前设备 |
| 查看日志 - 实时日志 / Debug 日志 | 查看设备运行日志 |
| 恢复默认 - TCP 端口 / 分辨率 / DPI | 还原设备默认设置 |
| 应用控制 - Shell 窗口 | 打开命令行 Shell |
| 应用控制 - 显示包名 | 显示系统 / 第三方 / 全部应用包名 |
| 应用控制 - 指定包名 | 启用 / 禁用指定应用 |
| 应用控制 - 一键禁用 | 批量禁用（仅特殊设备可用） |
| 断开所有设备 | 断开全部连接 |

> 也可将 APK 文件直接拖拽到设备行进行安装。

### 操作日志

点击菜单「查看日志」或右键设备的日志项，弹出「操作日志」窗口，记录每次操作的结果与状态；右键日志可「复制命令」便于排查。

### 设置与关于

- **设置**：勾选「置顶显示」让窗口始终在最前。
- **关于**：
  - **项目地址**：GitHub 主页（源码浏览）；
  - **项目地址（镜像）**：Gitea 仓库（`code.hcjike.com`）；
  - **检查更新**：从 Gitea 仓库的 Releases 拉取最新版本信息与安装包，发现新版本时提示更新。

## 常见问题

- **连接失败**：确认设备与电脑在同一局域网，开发者选项与无线调试已开启，且 IP/端口正确。
- **无法识别设备**：Android 11+ 需先完成配对再连接；旧版本系统可能不支持无线连接。
- **程序无法启动**：请确认已安装 `.NET Framework 4.6` 运行时。
